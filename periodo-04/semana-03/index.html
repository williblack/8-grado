La Tabla Facturador

Prof. William Fdo Bernal | Grado 8°

Objetivo: Comprender la estructura de una tabla de ventas y cómo se conecta con las tablas de consulta mediante IDs únicos para evitar errores en bases de datos.

📝 COPIAR AL CUADERNO

🔗 Conectando con la Semana 2:

Ya creamos las tablas de Artículos y Clientes. Ahora crearemos la tabla que une todo: el Facturador.

La Tabla Facturador

Es el "corazón" del negocio. Registra cada venta realizada sin escribir nombres largos, solo utilizando códigos.

  • ID_Factura: Llave Primaria (única).
  • Fecha: Día de la compra.
  • ID_Cliente: Código de quién compró.
  • ID_Articulo: Código de qué compró.
  • Cantidad: Unidades vendidas.
  • Total: Precio final.

Tablas de Consulta

Son listas de memoria que el sistema consulta rápidamente usando el ID.

Ejemplo Práctico:
Si en el facturador pongo ID_Articulo: A01, el sistema busca en la tabla Artículos y sabe que es un "Teclado Gamer".

🖥️ TRABAJO EN LA SALA

🛒 Actividad: "Mi Tiendita Virtual con IA + Excel"

Duración: 45 min Herramientas: Chat IA + Excel

1️⃣ Genera la estructura con IA (5 min) 🤖

Copia y pega este prompt exacto en tu chat de IA preferido:

"Actúa como experto en datos para 8°. Genera encabezados y 3 ejemplos para una tabla 'Artículos' (ID, Nombre, Precio) y 1 ejemplo para 'Facturador' (N_Factura, Fecha, ID_Producto, Cantidad, Total). Los IDs deben coincidir. Dame solo el texto separado por tabulaciones para pegar directo en Excel."

2️⃣ Crea la tabla 'Artículos' (10 min) 📊

  • Abre Excel → Libro nuevo. En A1 escribe: ID | Nombre | Precio
  • Copia los 3 productos de la IA y pégalos desde A2.
  • Selecciona A1:C4 → Ctrl + T → Aceptar.
  • Aplica formato Moneda a la columna Precio.
💡 Concepto clave: El ID es la "huella digital" única de cada producto. Nunca se repite.

3️⃣ Crea la tabla 'Facturador' (10 min) 🧾

  • Salta una fila. En A7 escribe: N_Factura | Fecha | ID_Producto | Cantidad | Total
  • Registra 1 venta imaginaria. Usa EXACTAMENTE un ID de la tabla Artículos.
  • En la celda Total, escribe la fórmula usando referencias de celda: =D8*C3 (Ajusta la celda C3 al precio que corresponda).
  • Selecciona A7:E8 → Ctrl + T.
🔗 Verifica: Si escribes un ID que no existe en Artículos, la relación de datos se rompe.

4️⃣ Revisa, reflexiona y guarda (10 min) 💾

  • En una celda libre (ej: A11) responde: "¿Por qué es crítico que los IDs coincidan entre tablas?" (1 línea).
  • Guarda con nombre EXACTO: 8_tienda_virtual_281124_TuNombre.xlsx

✨ Reto avanzado:

Pídele a la IA: "¿Cómo uso BUSCARV o XLOOKUP en Excel para que el precio se llene automático al escribir el ID en Facturador?" y prueba aplicarlo si terminas a tiempo.
